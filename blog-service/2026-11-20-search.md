Basic Mode, the structured query builder in Log Search, is no longer available. Log Search now uses the search text box for all queries, and the **Basic Mode** and **Advanced Mode** options no longer appear in the three-dot kebab menu. Your saved searches, scheduled searches, and monitors are not affected.

To build queries without writing the full query syntax, ask [Mobot](/docs/search/mobot) in plain language. Learn more about the [Log Search page](/docs/search/get-started-with-search/search-page).
