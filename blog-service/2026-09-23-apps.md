You can now migrate your existing AWS Observability Solution deployment from v2.x to v3.0.0 using new step-by-step guides. Whether you deploy with AWS CloudFormation or Terraform, and whether you prefer a manual walkthrough or an automation script, there's a documented path to get your stack onto the latest version.

### What's new

* Migration guide for CloudFormation deployments, with both a manual, step-by-step path and an automated script option.
* Migration guide for Terraform deployments.
* New v3.0.0 deployment documentation, published alongside the existing v2.15.0 docs so you can reference either version depending on which release you're running.

[Learn more](/docs/observability/aws/deploy-use-aws-observability/migration/).
