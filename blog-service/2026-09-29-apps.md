We’re excited to introduce the new Sumo Logic app for Amazon Security Lake. This app provides unified visibility into AWS security activity across accounts and regions using OCSF-normalized events. Pre-built dashboards help security teams monitor network, identity, application, and host activity to detect threats, investigate anomalies, and assess their AWS security posture. [Learn more](/docs/integrations/amazon-aws/amazon-security-lake).
