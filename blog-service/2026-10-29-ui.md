Effective October 29, 2026, newly created standalone Sumo Logic accounts default to the Sumo Logic UI and no longer have the option to switch to the Classic UI. Parent organizations, their child organizations, and existing accounts are not affected and keep their current UI settings for now.

* **New accounts default to the Sumo Logic UI**. Standalone accounts created through self-service signup or partner provisioning no longer have the option to switch to the Classic UI.
* **Other accounts are unaffected**. Existing customers, parent organizations, and their child organizations keep their current UI settings at this stage.
* **No data migration needed**. Your data carries over automatically between the Classic UI and the New UI.
* **Classic UI continues winding down**. The Classic UI will eventually be retired for all accounts. We'll share the exact date as it's confirmed.

[Learn more](/docs/get-started/sumo-logic-ui) about the Sumo Logic UI, or see the [Classic UI documentation](/docs/get-started/sumo-logic-ui-classic) if your account still has access to it.
