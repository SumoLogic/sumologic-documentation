### Automation service integrations

#### Enhancements

- **ZeroFox V2**. Enhanced the integration with new CTI enrichment actions and enhanced existing actions.
- **CrowdStrike Falcon**. Expanded the integration with new Case Management actions and deprecated legacy Incident actions.
- **Jira Cloud**. Improves Jira Cloud issue creation and updates for multiline/HTML descriptions and due-date inputs.
- **Atlassian Jira Cloud**. Added custom priority support to the Jira Cloud integration used by Cloud SOAR playbooks.
- **Atlassian Jira V2**. Added custom priority support to the Atlassian Jira V2 integrations used by Cloud SOAR playbooks.
- **ThreatConnect V3**. Added tag modes to indicator updates action and fixed bug in Search Intelligence action.

### App enhancements

- **Claude Compliance v1.0.2**. Updated Chats dashboard with tools information
