This month's updates cover new actions and fixes in five Automation service integrations, plus a refreshed Chats dashboard in the Claude Compliance app.

### Automation service integrations enhancements

- [ZeroFox V2](/docs/integrations/automation-integrations/zerofox-v2/). Added new CTI enrichment actions and improved existing actions.
- [CrowdStrike Falcon](/docs/integrations/automation-integrations/crowdstrike-falcon/). Expanded the integration with new Case Management actions and deprecated legacy Incident actions.
- [Atlassian Jira Cloud](/docs/integrations/automation-integrations/atlassian-jira-cloud/).
  - Improved Jira Cloud issue creation and updates for multiline/HTML descriptions and due-date inputs.
  - Added custom priority support to the Jira Cloud integration used by Cloud SOAR playbooks.
- [Atlassian Jira V2](/docs/integrations/automation-integrations/atlassian-jira-v2/). Added custom priority support to the Atlassian Jira V2 integrations used by Cloud SOAR playbooks.
- [ThreatConnect V3](/docs/integrations/automation-integrations/threatconnect-v3/). Added tag modes to the **Update Indicators** action and fixed a bug in the **Search Intelligence** action.

### App enhancements

- [Claude Compliance v1.0.2](/docs/integrations/saas-cloud/claude-compliance/#chats). Updated the **Chats** dashboard with tool information.
