### Automation service integrations

#### Enhancements

- **[ZeroFox V2](/docs/integrations/automation-integrations/zerofox-v2/)**. Enhanced the integration with new CTI enrichment actions and enhanced existing actions.
- **[CrowdStrike Falcon](/docs/integrations/automation-integrations/crowdstrike-falcon/)**. Expanded the integration with new Case Management actions and deprecated legacy Incident actions.
- **[Atlassian Jira Cloud](/docs/integrations/automation-integrations/atlassian-jira-cloud/)**
  - Improves Jira Cloud issue creation and updates for multiline/HTML descriptions and due-date inputs.
  - Added custom priority support to the Jira Cloud integration used by Cloud SOAR playbooks.
- **[Atlassian Jira V2](/docs/integrations/automation-integrations/atlassian-jira-v2/)**. Added custom priority support to the Atlassian Jira V2 integrations used by Cloud SOAR playbooks.
- **[ThreatConnect V3](/docs/integrations/automation-integrations/threatconnect-v3/)**. Added tag modes to indicator updates action and fixed bug in Search Intelligence action.

### App enhancements

- **[Claude Compliance v1.0.2](/docs/integrations/saas-cloud/claude-compliance/#chats)**. Updated Chats dashboard with tools information
