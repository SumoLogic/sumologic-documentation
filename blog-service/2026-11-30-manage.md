Data Pipelines help you parse, enrich, mask, filter, and route your logs from one visual graph. Each log message passes through only the first pipeline whose routing expression it matches, so you no longer need to manage the order of overlapping rules. [Learn more](/docs/manage/data-pipelines).

**What's new:**
- Route logs into a pipeline with a routing expression, and process them with ordered groups of processors and routers.
- Test a pipeline with sample data before you publish it.
- Monitor input and output data volume and health events for each pipeline.
