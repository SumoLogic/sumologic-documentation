- **Claude Compliance C2C v2.0.1**. The Claude Compliance C2C v2.0.1 adds **Activity Feed** collection alongside chat messages, with independent checkpoints and two new checkboxes in the source UI to control which data streams are collected (**Collect Chat Messages** and **Collect Activities**). Existing sources can be upgraded in place with no new collector setup needed. For more information, see [Claude Compliance Source](/docs/send-data/hosted-collectors/cloud-to-cloud-integration-framework/claude-compliance-source/) and [Claude Compliance App](/docs/integrations/saas-cloud/claude-compliance/).
- **ChatGPT Compliance C2C v2.0.2**. The ChatGPT Compliance C2C v2.0.2 expands event coverage with 6 new event types (`AUDIT_LOG`, `AUTH_LOG`, `APP_AUTH_LOG`, `APP_LOG`, `CODEX_LOG`, and `CODEX_SECURITY_LOG`), and widens the configurable polling interval from 5 minutes to 24 hours. Existing sources remain fully compatible; no upgrade is required. For more information, see [ChatGPT Compliance Source](/docs/send-data/hosted-collectors/cloud-to-cloud-integration-framework/chatgpt-compliance-source/) and [ChatGPT Compliance App](/docs/integrations/saas-cloud/chatgpt-compliance/).
- **Updated 18 setup guide apps**. Legacy ARM-based Azure Metrics Collection has been changed to the latest Azure Metrics Source.
- **SumoLogic Terraform Provider [v3.2.9](https://github.com/SumoLogic/terraform-provider-sumologic/releases/tag/v3.2.9)**. Released with new resource `sumologic_lambda_invoke_action`.
