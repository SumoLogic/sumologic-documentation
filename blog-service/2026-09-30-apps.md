### New release

#### AWSO v3.0.0

We're excited to announce the release of AWSO v3.0.0:
- **Complete rewrite** of the AWSO solution.
- **Expanded AWS region support**, including non-SAM regions and newly supported regions: Asia Pacific (Melbourne), Asia Pacific (New Zealand), and Europe (Zurich).
- **Support for AWS regions launched after August 2022**, with the appropriate Load Balancer policies configured automatically.
- **Terraform Module support** for solution deployment, including release versioning.
- **Next-generation application support** with out-of-the-box dashboards, monitors, FERs, and metric rules.
[Learn more](/docs/observability/aws/deploy-use-aws-observability/v3.0.0/).

#### Enhancements

- [1Password](/docs/platform-services/automation-service/app-central/integrations/1password/). Migrated to 1Password v1 APIs, improved integration stability, and added filtering support to the List Users action.
- [AWS CloudWatchLogs](/docs/platform-services/automation-service/app-central/integrations/aws-cloudwatchlogs/). Added new metric actions: **Get Metric Data**, **List Metrics**, and **Get Metric Statistics**.
- [Azure AD](/docs/platform-services/automation-service/app-central/integrations/azure-ad).
    - Added Delegated (Device Code Flow) authentication support alongside existing Application (Client Credentials) auth.
    - Added new actions (Delegated auth only): **Initiate Delegated Auth**, **Exchange Device Code**, and **Reset User Password With Writeback**.
    - Added new integration resource fields: Authentication Type, Delegated Refresh Token.
- [CrowdStrike Falcon Sandbox](/docs/platform-services/automation-service/app-central/integrations/crowdstrike-falcon-sandbox/). Added OAuth 2.0 (Client Credentials) authentication support and new Check Submission Status action.
- [Microsoft Graph Security](/docs/platform-services/automation-service/app-central/integrations/microsoft-graph-security/).
    - Migrated **Get Alert**, **Search Alerts**, and **Update Alert** actions to the new Microsoft Graph Security [alerts_v2](https://learn.microsoft.com/en-us/graph/alertsv1-alertsv2-migration) API. The legacy `/security/alerts` endpoint is deprecated and will be retired on October 15, 2026.
    - Legacy actions **Search Into Alerts** and **Update Security Alert** are retained for backward compatibility, as the alerts_v2 API is not a one-to-one replacement for the legacy API and some alerts may be unavailable through the new endpoint.
- [Sumo Logic Cloud SIEM](/docs/platform-services/automation-service/app-central/integrations/sumo-logic-cloud-siem/). Added new actions: **Get Insight Triage** and **Check Insight Triage Schedule**.
