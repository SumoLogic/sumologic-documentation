The Log Analysis Agent now works in the background to recommend monitors for searches your team keeps repeating, so you can close coverage gaps before the next incident. It also flags duplicate and debug logs that add to your ingest volume. Recommendations appear in the Recommendation Hub, where you review each one and decide what to do. This feature is in Public Preview. [Learn more](/docs/search/mobot/log-analysis-agent).

**What's new:**
* **Create monitor**. Turns repeated searches into monitor recommendations with the query and an alert threshold filled in.
* **Remove duplicate logs**. Detects identical log streams that are ingested more than once.
* **Reduce debug log ingestion**. Flags debug logs that run continuously in production.
