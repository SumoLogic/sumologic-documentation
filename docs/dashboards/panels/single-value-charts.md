Single value charts display the result of a log or metric query as one value, for at-a-glance analysis. This page shows you how to create and customize single value charts.

A single value chart displays one record from a search so the value stands out at a glance. If the query returns more than one value in the **Aggregates** tab, only the first value is displayed in the single value chart.

A single value chart is useful for summarizing a time series as one number. For example, you might want a dashboard panel that shows the number of errors generated by your site over the last 24 hours.

## Create a Single value chart

To add a panel with a single value chart:

1. Create or open a dashboard and click **Add Panel > Single Value**.<br/><img src={useBaseUrl('/img/dashboards/panels/single-value-charts/single-value-pane.png')} alt="single value pane" style={{border: '1px solid gray'}} width="600" />
1. Provide a Metrics or Logs query and press **Enter** for it to run.

    **Log query:**

    Enter your aggregate [search query](/docs/search/search-query-language/group-aggregate-operators) in the text box and press **Enter**. Only search results that have been aggregated using a group or aggregate operator can be charted. See [Group or Aggregate Operators](/docs/search/search-query-language/group-aggregate-operators) for a list. By default, the query builder is set to **Logs**.<br/><img src={useBaseUrl('/img/dashboards/create-dashboard/Add-log-query.png')} alt="Add log query" style={{border: '1px solid gray'}} width="700" />

    **Metrics query:**

    Click the left-most dropdown option and select **Metrics**. For best results, learn the basics of creating [metrics queries](/docs/metrics/metrics-queries) first. By default, the query builder is set to **Logs**.<br/><img src={useBaseUrl('/img/dashboards/create-dashboard/Add-log-query.png')} alt="Metrics selection for query builder" style={{border: '1px solid gray'}} width="700" />

    Build the metrics query in [Metrics Search](/docs/metrics/metrics-queries/metrics-explorer.md).<br/><img src={useBaseUrl('/img/dashboards/panels/single-value-charts/new-single-value-chart-metrics.png')} alt="new single value chart metrics" style={{border: '1px solid gray'}} width="800" />

1. [Modify the chart](./modify-chart.md) as desired.
1. Click the **Add to Dashboard** button on the top right of the window to add the panel to your dashboard.<br/><img src={useBaseUrl('/img/dashboards/create-dashboard/Add-to-Dashboard-button.png')} alt="Add to Dashboard button" style={{border: '1px solid gray'}} width="300" />

### Boolean

A boolean single value chart displays a value as true or false. For example, the following query checks whether the search finds more than 100 errors.

```sumo
error | count as MyCount | if (MyCount> 100, true, false) as MyCount
```

The boolean single value chart would look like the following.<br/><img src={useBaseUrl('/img/dashboards/panels/single-value-charts/Dashboard-New-boolean-single-value-chart.png')} alt="Dashboard boolean single value chart" style={{border: '1px solid gray'}} width="700" />

## Sparkline

The **Sparkline** option is available for metrics and logs queries. For a log query, include a [`timeslice`](/docs/search/search-query-language/search-operators/timeslice) operation and [`sort`](/docs/search/search-query-language/search-operators/sort) the timeslice in the query so the sparkline renders correctly.
