The SIEM Content Catalog is a public GitHub repository of SIEM's rules, schema, mappings, and parsers. This repository serves as a single place to view SIEM content in both markdown form and CSVs. This catalog is automatically generated based on content included out-of-the-box as it is released. 

Access the SIEM Content Catalog here:
[https://github.com/SumoLogic/siem-content-catalog](https://github.com/SumoLogic/siem-content-catalog/blob/master/README.md)

The catalog contains information on the following: 

| Category | Description |
| :-- | :-- |
| Rules	| Platform logic within the SIEM product. |
| Schema | Data model in which data is normalized and enhanced. |
| Mappings | How data from various formats is normalized and transformed into the SIEM schema. |
| Parsers | Log parsers that extract key value pairs from raw log data. |
| Products | Products and log types we support. |
| Vendors | Vendors that supply products supported by SIEM |
