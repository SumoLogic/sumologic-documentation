API integrations connect Sumo Logic to other tools and services through their APIs. Each integration offers a fixed set of actions that you add to playbooks. You can use them across playbook automation workflows and with Dojo AI agents.

To get started, see:

- [Installing and Upgrading Automation Integrations](/docs/integrations/outbound/integrations-via-api/install-automation-integrations/). Install an integration from the catalog and keep it up to date.
- [Configure Authentication for Automation Integrations](/docs/integrations/outbound/integrations-via-api/configure-authentication/). Set up the connection an integration uses to sign in to the service.

If the service you need is not in the catalog, add a custom API integration. In App Catalog, open the **Integrations** tab, select **Outbound Integrations**, click **+ Add Custom**, and select **API Integration**. To learn more, see [Outbound Integrations](/docs/integrations/outbound/#add-a-custom-integration).
