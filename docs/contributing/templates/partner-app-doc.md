:::important
Most Partner Ecosystem apps are documented on the partner's own website or in the [sumologic-public-partner-apps](https://github.com/SumoLogic/sumologic-public-partner-apps) GitHub repo, not as an individual page on this site. Use this template only if you're creating a new, individually hosted partner app doc here.
:::

For [Sumo Logic Partner app](/docs/integrations/partner-ecosystem-apps) docs, follow the [apps template](/docs/contributing/templates/app-template-v2), and append this at the end:

```md
## Support

This application has been developed and is supported by `{app-owner-name}`. In case of any technical queries, contact support at `support contact`.
```
