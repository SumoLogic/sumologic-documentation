:::warning EWS retirement for Exchange Online
Microsoft is retiring Exchange Web Services (EWS) in Exchange Online. Disablement begins October 2026, with full disablement by April 2027. This integration is affected.

For new Exchange Online configurations, use [Microsoft EWS (Graph)](/docs/integrations/automation-integrations/automation-integration-catalog/microsoft-ews-graph) instead. See [Microsoft's retirement announcement](https://learn.microsoft.com/en-us/exchange/clients-and-mobile-in-exchange-online/deprecation-of-ews-exchange-online) for details and timeline.
:::
