OT Collector registrations that use `clobber: true` are now rate limited for each collector name. After about 50 registration attempts with the same name within an hour, Sumo Logic rejects further attempts with an HTTP `429` response. This prevents multiple machines that share a collector name from repeatedly deleting and re-registering each other's collectors. To avoid the limit, use a unique `collector_name` for each machine, and use `clobber` only to replace a collector that is no longer running. [Learn more](/docs/send-data/opentelemetry-collector/data-source-configurations/additional-configurations-reference/#clobber-rate-limiting).
