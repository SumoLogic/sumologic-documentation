* This content release includes:
    - Support for Azure Firewall resource-specific logs across the Azure Firewall mappers and deny-event rules, so firewall deny detections now work with additionl event formats
    - Improved Palo Alto Networks success and outcome mapping across threat and traffic logs, so events are no longer assigned a default result when the log doesn't indicate one
    - Enhanced Microsoft SQL Server authentication parsing and mapping for more accurate failure cause details
    - New log mappers for CrowdStrike Falcon correlation rule detection summaries and GCP Cloud Run requests
    - Additional changes are enumerated below
