## Browse and import community and Sigma rules

You can now browse a library of community rules, including rules from the Sigma project, and import them into Cloud SIEM without running a conversion step. Cloud SIEM has already translated these rules into Cloud SIEM rule format, so you can expand your detection coverage without writing rules from scratch.

On the **Rules** page, click **Browse Available Community/Sigma Rules** to open the library. Filter and sort the list, open a rule to compare the original Sigma rule with the translated Cloud SIEM rule, and import one rule or many at once. Imported rules are templated match rules, and you can find them in the **Rules** list by filtering on **Source**. [Learn more](/docs/cse/rules/about-cse-rules/#browse-community-and-sigma-rules).
