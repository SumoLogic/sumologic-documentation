## Create and Edit Rules with Mobot

A new Mobot skill in Sumo Logic lets you create and edit Cloud SIEM rules from plain-language prompts, instead of writing rule expressions and configuring each field manually. Describe the detection you want, and Mobot proposes the rule, asks clarifying questions, and builds it for you. Mobot supports all Cloud SIEM rule types except Legacy rules. [Learn more](/docs/cse/rules/create-rules-with-mobot/).
