### SOC Analyst Agent: Recommended actions and response

After the SOC Analyst Agent triages an insight, it now recommends response actions that you can review and run without leaving Cloud SIEM. Every action requires your approval, so the agent never acts on its own. [Learn more](/docs/cse/get-started-with-cloud-siem/soc-analyst-agent/#recommended-actions-and-response).

* View **AI Recommended Actions** in the **Insights** list side panel, on the insight's **Overview** and **AI Investigation** tabs, and in Mobot.
* Click **Execute** to run an action when its integration is installed. Other recommendations appear as text-only suggestions.
* Review the audit trail, which logs every action, analyst decision, and execution result.
