## SOC Analyst Agent: Investigation trace

You can now see how the SOC Analyst Agent reached its verdict on an insight. Click **View Full Investigation Process** on the insight's **AI Investigation** tab to review each step the agent took, the queries it ran, and the findings behind its conclusion. [Learn more](/docs/cse/get-started-with-cloud-siem/soc-analyst-agent/#view-the-investigation-trace).

## SOC Analyst Agent: Recommended actions

The SOC Analyst Agent now triages Cloud SIEM insights and produces **Recommended Actions** for resolution that you can review directly in Cloud SIEM. Executing a recommended action remains in [Private Preview](/docs/cse/get-started-with-cloud-siem/soc-recommendation-and-response/). [Learn more](/docs/cse/get-started-with-cloud-siem/soc-analyst-agent/#recommended-actions).

## SOC Analyst Agent: Settings moved to Dojo Studio

You now manage SOC Analyst Agent settings, including tasks, triggers, volume, and overage, in Dojo Studio. The SOC Analyst Settings tab on the Cloud SIEM Workflow Configuration page is no longer used. [Learn more](/docs/cse/get-started-with-cloud-siem/soc-analyst-agent/#configure-soc-analyst-agent-settings).
