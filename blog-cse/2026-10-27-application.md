## Multi-column sorting on the Insights list page

You can now sort the Cloud SIEM Insights list by more than one column.

- Hold **Shift** and click additional column headers to add secondary and tertiary sorts.
- Click a column header without holding **Shift** to reset the list and sort by that column alone.
- Bulk updates support only a single-column sort. When you select all insights for a bulk action, the list is sorted by the primary sort column only, and any secondary sort rules are ignored.

For more information, see [Sort insights](/docs/cse/get-started-with-cloud-siem/about-cse-insight-ui/#sort-insights).
