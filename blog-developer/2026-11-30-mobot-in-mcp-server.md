Mobot is now a tool in the [Sumo Logic MCP Server](/docs/api/mcp-server). MCP-compatible clients such as Claude Code and GitHub Copilot can run Mobot investigations across your logs, metrics, and telemetry, so you can keep working in your IDE or terminal. Learn more in [Mobot in the MCP Server](/docs/api/mobot-in-mcp-server).

Administrators can turn Mobot in the MCP server on or off in Feature Management. It is on by default.
